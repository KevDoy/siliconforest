# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Its text applies here by reference.

In short: be respectful, assume good faith, criticise code and not people, and give credit
generously, in particular to the projects this one is built on.

To report a problem, contact the maintainer privately through GitHub (the maintainer's
profile, or the private reporting feature described in [`SECURITY.md`](SECURITY.md)).
